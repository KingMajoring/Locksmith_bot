{% comment %} Camera-or-gallery photo picker for one named slot — used by job_complete, job_photo_upload and job_access_method. Args: kind (e.g. "front_of_car"), required (bool). Both buttons drive the SAME file input (so the existing per-page "max 3" script, the site-wide compression script in base.html, and required-field validation all keep working unchanged) — "Take photo" just sets capture=environment on it first so the OS opens the camera directly instead of the file/gallery chooser. The input is visually hidden via CSS (.photo-file-input), NOT the `hidden` attribute — a display:none file input silently refuses to open on some mobile browsers when clicked programmatically (confirmed live on both iOS Safari and Android Chrome). {% endcomment %}
